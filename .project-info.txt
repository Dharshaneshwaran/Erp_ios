API INTEGRATION
================================================================================

Connected Endpoints:
- POST   /auth/login       - User login
- POST   /auth/refresh     - Token refresh
- GET    /auth/me          - User profile

Request Format:
{
  "email": "user@example.com",
  "password": "password123"
}

Response Format:
{
  "accessToken": "jwt_token",
  "refreshToken": "jwt_token",
  "expiresIn": 3600,
  "user": { ... }
}
